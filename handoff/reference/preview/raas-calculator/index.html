Read the assumptions.

“Workers per shift” is multiplied by shifts, 8 hours per shift, working days and 4.33 weeks per month. Turnover replacement cost is assumed to be 75% of annual base pay.

Cashable labour reduction must reflect an actual reduction or avoided spend. Extra output has no cash value here unless you explicitly recognise incremental productivity value. Do not count the same output twice.

The model assumes the proposed robot fleet can support the workload. Validate capacity, ramp-up, downtime, integration, staffing and ongoing costs before making a decision. No discounting, taxes or residual value are modelled.
